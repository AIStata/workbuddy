Task 1｜认识 WorkBuddy 与安全起步

装上它，守好边界

1.1 Agent 工具介绍

核心能力（六项）

  1. 自然语言交互：用一句话描述需求，无需预先拆分复杂操作步骤。
  2. 自主规划与执行：根据任务目标自动拆解步骤、规划流程并完成。
  3. 多模态任务处理：支持文档、表格、PPT、数据分析等多种任务类型。
  4. 本地文件操作：授权后可读取和处理本地文件，支持批量整理、修改。
  5. 多任务并行：可同时创建和处理多个任务，适合并行推进不同工作。
  6. 结果交付与验收：完成后可在结果区查看和使用生成的成果。

与传统 AI 对话的区别

对比项 传统 AI 对话 WorkBuddy
任务执行 只能对话，提供建议 能够实际执行任务
文件操作 需要手动操作文件 自动操作本地文件
任务复杂度 单步骤简单任务 多步骤复杂任务
输出 输出文字回复 交付可验收的结果

适用场景

场景 能做什么
日常办公 写文档、做分析、查资料、整理信息，把琐碎任务交出去
代码开发 写代码、读项目、开发网站和应用
设计创意 从想法出发生成图片、PPT、网页等设计内容
项目协作 围绕项目持续处理任务、使用项目资料
专业任务 用专家和技能复用专业知识与工作方法
服务协作 通过连接器接入第三方服务，访问外部数据
资料与知识 集中管理资料，基于资料检索、分析和生成内容

认识工作界面

区域 功能
工具栏 屏幕顶部，提供关于、编辑、窗口等常用操作入口
侧边栏 显示任务列表（按文件夹分组），支持搜索管理；底部为用户头像
对话区 核心交互区，含任务标题栏、消息列表和输入框
结果区 右侧面板，提供「概览」与「产物」两类内容，可切换查看
提示

官方建议的阅读顺序：创建任务 → 任务管理 → 任务对话 → 结果查看。

1.2 WorkBuddy 安装与登录

环境要求

  • Windows：Windows 10 及以上，支持 x64；不支持 Windows 7/8/8.1。
  • macOS：macOS 12（Monterey）及以上。

Windows 安装

  1. 访问官网点击「立即下载」，选择 Windows，下载安装包。
  2. 双击安装包启动安装程序，勾选「我同意此协议」，点击「下一步」。
  3. 选择安装路径（默认可直接下一步），确认开始菜单文件夹。
  4. 建议勾选「创建桌面快捷方式」，确认配置后点击「安装」。
  5. 安装完成后点击「完成」退出向导。
说明

安装用户建议选择「仅为我安装」。更新入口：头像 →「检查更新」，系统自动检测并升级。

Mac 安装

版本选择：M 系列芯片选 Mac ARM64，Intel 芯片选 Mac X64；官网未识别设备时默认给 X64（可通过 Rosetta 在 M 系列运行，兼容性更广）。查版本：左上角苹果图标 →「关于本机」。

  1. 双击下载的 .dmg 文件，打开安装窗口。
  2. 将 WorkBuddy 图标拖入 Applications（应用程序） 文件夹。
  3. 等待拷贝完成后，推出磁盘映像，可删除 .dmg 安装包。
注意

务必拖入「应用程序」文件夹后再启动。若直接从磁盘映像运行，WorkBuddy 将运行在只读映像上，后续无法自动更新。如检查更新失败，可点击提示中的「移动到应用程序」一键修复。

登录

  1. 启动 WorkBuddy，点击「登录」，浏览器自动打开登录页（workbuddy.cn）。
  2. 勾选《用户服务协议》与《隐私政策》，使用微信扫码完成登录。
  3. 页面显示登录成功后，返回客户端即可开始使用。

也支持手机号、邮箱、SSO 等方式，全程在当前页面完成。个人用户选「个人」，企业版用户选「企业」。语言切换：头像 → 设置 → 通用 → 语言。

1.3 任务与项目管理

开启第一个任务

  1. 微信扫码登录。
  2. 点击「新建任务」创建 PC 端任务。
  3. 在对话框中描述需求。
  4. 点击「发送」，WorkBuddy 开始执行。
  5. 打开右侧窗口查看结果：目标文件在「产物」，其他文件在「概览 → 工作空间文件」。
提示

移动端发送的任务在「助理」中查看。WorkBuddy 可连接小程序、App，接入微信助理、企微助理、QQ 机器人、飞书、钉钉机器人等。

任务状态与筛选

官方定义六种任务状态：进行中、已完成、失败、待处理、规划中、已归档。窗口左上方提供「搜索」与「筛选」：

  • 搜索：可检索任务、空间、产物与资料库，结果分五类，命中关键词高亮。
  • 筛选：支持按状态（进行中/已完成/失败等）和日期筛选，可一键重置。

侧边栏对「已完成未读、失败（红色感叹号）、待确认」等状态做标记，分组收起时按 待确认 > 已完成未读 > 失败 > 进行中 逐层聚合。

继续处理与常用操作

已完成、失败或中断的任务都可重新进入，在已有上下文基础上继续补充消息。悬停任务行点「⋯」或右键可：置顶、重命名、分享任务（生成公开链接）、独立窗口打开、保存到工作空间（可开启多个 Agent 协作）、归档、删除等。

警告：删除任务不可恢复：删除后将从所有设备移除；运行中的任务删除会立即终止。正在运行的任务无法批量删除。

常用快捷键：Ctrl/⌘+K 全局搜索、Ctrl/⌘+Shift+E 定位当前任务、Ctrl/⌘+[ ] 切换上一个/下一个任务。

项目：团队协作能力

项目通过「项目 + 任务」两层结构，让团队共享上下文、标准与知识。项目把指令、连接器、专家、技能和资料统一组织，成员发起任务时这些配置自动注入，无需重复设置。

要点 说明
项目配置 名称（必填）、指令（全局规则，所有任务继承）、连接器、专家、技能
邀请成员 点「邀请」→ 复制链接 → 对方申请 → 管理员在消息中心审批
任务流转 打包产物、进度摘要、自定义字段与附件，接收方基于完整上下文继续
项目资产 统一文件管理中心，以 RAG 形式注入上下文；每项目默认 5 GB 空间
项目配置目录 .codebuddy/rules/、agents/、skills/、commands/、CODEBUDDY.md，项目级优先于用户级

1.4 移动端访问（助理 / 远程任务）

「助理」是 WorkBuddy 的远程控制功能，官方比喻为遥控器：手机发一条消息 → 电脑上的 WorkBuddy 自动执行 → 结果回复到手机。支持微信助理（推荐）、微信客服号、企微助理、QQ 机器人、飞书、钉钉机器人。

典型场景：出门在外让电脑处理文件、会议中生成纪要、通勤路上准备材料、随时随地派发任务。

对比项 普通任务 助理（远程任务）
工作目录 自由指定 固定使用「助理」专属文件夹
新建对话 支持多个并行任务 仅一个会话，所有远程指令集中处理
上下文管理 可清空历史重新开始 保留完整历史，不可清空

配置三步：头像 → 设置 → 助理设置 → 按需配置平台集成 → 按提示完成。使用时电脑需保持开机并运行 WorkBuddy、网络正常。微信客服号可直接扫码绑定，企业微信/QQ/飞书/钉钉通常需先在对应平台完成应用或机器人配置。

要点

安全边界：绑定身份（可灵活换绑）、来源校验（多层校验每条指令）、高风险任务确认（文件删除、系统配置修改、命令执行需确认）。解绑在「助理设置」中点卡片右侧「解绑」。

1.5 权限模式与安全设置

WorkBuddy 提供默认权限和完全访问权限两种模式。官方把它比作一层安全护栏：日常不挡路，真正越界或危险动作时请你再确认一次。切换入口在输入框底部的常驻权限状态按钮。

对比项 默认权限 完全访问权限
文件访问范围 沙箱约束内，越界需请求允许 计算机上任意位置
删除/修改文件 需逐次确认 多数直接执行
终端命令 系统级命令需确认 可直接运行、安装软件、改系统设置
访问互联网 受控，敏感动作需确认 可访问网站、发送数据
打断频率 / 风险 较高 / 低 很低 / 高
生效范围 当前任务 当前客户端内所有任务，不跨设备

默认权限重点保护：写入受保护/敏感路径、删除重要文件或批量删除、执行脚本命令或外部程序、网络访问或敏感能力。取消确认则不会执行。沙箱还提供命令约束、删除保护（回收站）、文件备份。

注意

不建议开启完全访问的场景：处理生产/客户/财务资料或唯一副本；工作目录靠近桌面、下载或项目根目录；任务会批量删除/重命名/覆盖；需运行不了解的脚本；电脑有重要文件且无备份。仅在 Docker、虚拟机、一次性目录等可隔离环境短时开启，用完即关。

安全中心

安全中心做比权限模式更细粒度的控制，统一管理安全、数据保护与运行环境，主要分组：

分组 主要配置项
沙箱安全 总开关；文件安全（按路径设允许/询问/拒绝）；命令安全（按前缀）；网络安全（按域名/URL，macOS 支持严格模式）；自动备份
工具管控 按工具、MCP 服务及工具粒度启停，对客户端所有 Agent 生效；自定义 MCP 统一开关
AI 安全防护 模型行为智能审查、工具内容注入防护、AI 智能审批（三项默认关闭）
数据安全 安全网关、传输加密、敏感保护、删除保护、批量删除审批（默认 50）
内置运行时 / 审计 内置运行时工具；审计中心记录拦截/放行日志，支持导出

自动备份默认开启：修改已有文件前生成快照（约 3000 MB 上限，满了按时间清理最早备份），用于在改错时快速回退，不替代你自己的重要备份。敏感保护默认开启，用关键词/正则/熵值检测 API Key 等敏感信息，命中后可选「允许访问 / 允许加密访问（推荐）/ 禁止访问」。

说明

工作区信任：首次打开含 .codebuddy 等开发配置且未加白名单的工作区时会弹信任弹窗。选「受限模式」时仍可浏览编辑，但不扫描/运行配置目录下文件、不自动加载规则脚本、不自动启动相关 Agent。信任以工作区目录为单位。
