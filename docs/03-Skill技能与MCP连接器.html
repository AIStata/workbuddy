Task 3｜Skill 技能与 MCP 连接器

用好现成工具

3.1 技能介绍

官方定义：技能（Skill）用于扩展 WorkBuddy 的能力，通过封装脚本与工作流，帮助完成发送邮件、读写文件、查询信息等特定任务（如订外卖、查询股价、调用第三方 API 等）。

  • 本质：把「脚本 + 工作流」封装成可复用的能力模块。
  • 来源：技能市场（推荐/SkillHub/套件）、本地上传、对话中创建。
  • 安全：非官方 Skill 可能存在恶意提示词注入、越权访问、后门等隐患，安装前请校验来源、权限申请与脚本内容，优先使用官方推荐 Skill。
  • 成本：复杂任务与复杂 Skill 通常积分消耗较高。
  • 权限：Skill 调用第三方、改本地文件、执行系统命令时均以你本人身份执行，涉及删除/批量写入/资金类操作建议先小范围验证。

3.2 技能安装与使用

入口：左侧边栏点击「专家·技能·连接器」→「技能」页签。板块分两区：

区域 内容
技能市场 按推荐、SkillHub、套件分类展示，可一键安装；卡片显示使用量与安装量，支持按综合/使用量/安装量/更新排序
已安装 已装在本地的技能，可直接在对话中调用

四种获取方式

  1. 技能页面添加：点击技能卡片右上角「+」，提示安装成功。
  2. 对话安装：直接说“帮我找一个能把网页转成 PDF 的技能”，WorkBuddy 自动搜索市场并展示候选，确认后安装（仅限市场内技能）。
  3. 上传技能：「添加技能 → 上传技能」，拖拽或选择本地技能包，导入后自动配置。
  4. 创建/查找技能：「添加技能 → 创建技能」输入描述自动创建；「查找技能」自动查找并安装。

管理

  • 启用/关闭：关闭后仍保留在列表，不再参与新任务调用；状态多端同步；关闭 ≠ 卸载（卸载才彻底删除）。建议仅启用当前任务所需技能。
  • 搜索：技能较多时用搜索框按关键词定位。
  • 卸载：已安装 → 选中技能 →「⋯」→ 卸载；或用「批量管理」批量卸载。

3.3 常用技能推荐

以下为官方「零成本 Skill Top 10」系列中代表性的几项：

Find Skills（找技能） find-skills

根据需求快速筛选候选 Skill 并解释差异。真正的门槛往往不是安装，而是选择。

场景：不确定是否已有现成技能、想让 AI 先筛一轮、快速了解候选区别。

Web Search（网页搜索） web-search

遇到“最近/最新/现在”类时效问题时，先搜索、再整理、再回答，降低信息过期误判。

场景：查最新资料、找新闻、收集某领域信息、先查后写。

办公文档四件套（内置指令）

PDF 抽正文/表格/OCR/拆合；DOCX 生成文档/补目录页码；PPTX 读幻灯片/重做演示；XLSX 清洗表格/补公式/汇总。

Agent Browser（浏览器） agent-browser

直接在网页中执行打开、滚动、点击、展开、截图和读取信息，适合必须交互后才可见的内容。

Frontend Design（前端设计） frontend-design

生成前端页面时兼顾设计感、风格一致性和演示效果，而不只是可运行代码。

Self-improvement / Skill Scanner

前者记录经验偏好、越用越贴合习惯；后者在安装前审查第三方 Skill 的可疑依赖与硬编码配置。

提示

用法示例：“请帮我搜索最近 1 个月 AI 办公工具领域的重要动态，整理成要点摘要，并附上来源链接。”——带上时间范围、要求附来源、先查后写，是官方推荐的最佳实践。

3.4 连接器原理

官方定义：连接器用于将 WorkBuddy 与外部服务对接，将外部数据和能力引入 AI 工作流；在获得授权后访问和操作第三方服务，实现数据互通与能力扩展。

实现形态分两类：MCP + CLI（标准化协议）和 Skill + CLI（内置脚本），二者在数据收集和权限边界上遵循一致原则。已支持 QQ 邮箱、腾讯文档、腾讯乐享、腾讯会议、TAPD、腾讯网盘，并支持自定义连接器。

场景 说明 示例
数据查询 从外部数据源获取信息 查询数据库、检索文档
服务调用 调用第三方 API 完成操作 发送邮件、创建日程
文件管理 访问云端存储与文件系统 读取网盘文件、上传附件
消息通知 与即时通讯工具集成 发企业微信/飞书消息
要点

权限边界：每个连接器独立授权；不主动定时抓取；不超出你已有权限范围。积分：连接器自身读写不消耗积分，WorkBuddy 对外部数据进行理解、汇总时才消耗。

3.5 连接器使用

添加四步

  1. 侧边栏「专家·技能·连接器」→「连接器」页签。
  2. 找到目标连接器，点卡片右上「+」。
  3. 按提示完成登录、授权或配置。
  4. 授权完成后即可使用。

三种使用方式

  • 页面发起：在连接器页面点「去对话」。
  • 创建任务时启用：输入框左下「+ → 连接器」，弹窗中开启。
  • 执行中按需连接：任务中需要未连接的连接器时，输入框上方出现引导卡片，授权后自动继续执行。

QQ 邮箱连接示例

  1. 点卡片「+」发起连接，跳转授权页显示二维码。
  2. 用 QQ 邮箱 App 扫码（7.1.5 / 鸿蒙 0.2.9 及以上）。
  3. 手机端确认权限：账号信息、读取近一个月邮件、发送邮件、删除邮件（可选），点「同意授权」。
  4. 手机显示「授权成功」。
  5. 回到 WorkBuddy，卡片旁出现绿色圆点，提示「已连接」。
注意

授权失效：输入框上方出现「连接器需要重新连接」卡片，点「重新连接」完成授权后自动重试失败步骤（同一步骤只自动重试一次）。网络超时、服务异常、无权限不会触发此卡片。停用：「+ → 连接器」关闭启用；解绑：管理页选中连接器点「解绑」（内置连接器不支持卸载）。

3.6 连接器 vs 技能

两者分工互补：连接器负责“把外部数据与服务带进来”，技能负责“用脚本与工作流把事情做出来”。依据官方定义归纳如下：

维度 技能（Skill） 连接器（Connector / MCP）
定位 扩展能力，封装脚本与工作流 对接外部服务，引入外部数据与能力
实现形态 脚本 + 工作流 MCP + CLI、Skill + CLI
来源 技能市场、本地上传、AI 创建 官方已支持服务 + 自定义 MCP
授权 安装启用时授权，第三方需校验 每个连接器独立授权（OAuth/API Key/扫码）
积分 复杂技能消耗较高 自身读写不耗，理解/汇总外部数据时消耗
第三方交互 部分技能可能外发输入 本质即与外部服务交互，凭据由 WorkBuddy 维护
说明

官方未设专门的“连接器 vs 技能”对比章节，上表依据两处官方定义归纳。实际使用中二者常在同一任务里协同：如 Web Search 先查后整理、办公文档技能生成导出、连接器提供外部数据。
