书籍简介

这是一本面向 WorkBuddy 新用户的上手指南。全书按六个任务模块组织，从”装好它、守住边界”开始，一路讲到提示词与模型、技能与连接器、深度调研实战、专家与团队协作，最后落到资料库与记忆。

  • 核心内容：涵盖安全起步、Prompt 提示词与模型选择、Skill 技能与 MCP 连接器、技能实战与深度调研、专家与团队、资料库与记忆六大模块；
  • 官方文档：术语、按钮名称与操作步骤均保留 WorkBuddy 官方表述，共 26 个小节；
  • 如实标注：对官方文档未公开详述的部分（如 SKILL.md 文件规范、身份文件格式、子 Agent 配置细节），以”说明”形式标注，未作臆测；
  • 独立成篇：每一章都可以单独阅读，连起来则是一条完整的学习路径。

本书适用于 WorkBuddy 新用户、希望系统掌握 Agent 工具使用的从业者，既可作为入门教程，也可作为功能速查手册。

如何使用本书

  • 导航方式：左侧侧边栏可浏览全部章节结构（默认全部展开），支持关键词搜索（输入框位于侧边栏顶部）；
  • 阅读模式：每页右侧目录可跳转到本页小节，点击标题锚点可定位到具体段落；
  • 二次编辑：源文件为 .qmd（Markdown 兼容），可直接修改内容后在本书目录运行 quarto render 重新编译；
  • 版本更新：若功能有更新，请以 WorkBuddy 官方文档为准，本教程将持续迭代。
