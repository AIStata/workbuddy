Task 2｜Prompt 提示词与模型选择

说清楚，选对大脑

2.1 提示词与上下文

也可以点击输入框的「语音输入」按钮口述需求，语音实时转为文字（Mac 左 ⌥、Windows Alt 点击或长按）。

官方示例：

  • “帮我把这份销售数据生成一个分析报告，包含图表”
  • “整理 Downloads 文件夹里的图片，按日期分类”
  • “根据这份会议纪要生成一个 PPT”
  • “调研一下 2024 年 AI 行业趋势，写一份报告”

添加上下文的四种方式

方式 说明
引用上下文 通过 @ 引用文件、文档、规则等信息
粘贴截图 Ctrl/⌘+V 直接粘贴剪贴板图片
上传文件 点击上传按钮或拖拽文件到输入框
补充说明 在描述中明确目标、范围、约束和预期输出
提示

官方建议优先补充四类信息：① 目标是什么（要生成什么/处理什么文件）；② 输入是什么（要分析的数据、参考文档）；③ 输出格式（Word/Excel/PPT 等）；④ 约束条件（风格、字数、截止时间等）。

补充细节：@ 还可唤起「浏览器操作」等能力；文件可直接拖拽到页面任意位置，最多 50 个、单个大小不限，添加后不会自动发送；粘贴超 3000 字符自动收起为可展开条目。上传格式支持 PDF、Word、TXT、Markdown、Excel、CSV、PPT、图片、压缩包及常见代码文件。所有文件处理默认在本地完成，原始数据不上传云端。

工作空间是上下文的载体：点击输入框左下角「选择工作空间」指定目录，WorkBuddy 在其中读写文件。建议按任务类型分别建立，如「发票整理」「周报」「待处理照片」。

2.2 需求表达

技巧一：三要素公式「做什么 + 有什么 + 怎么样」

反面示范

“帮我把上次的会议纪要整理一下。”

信息太少，WorkBuddy 不会读心术，发挥空间混沌。

正面示范

“把 D:/会议纪要/0320产品评审.docx 整理成清单：1）每个议题的结论；2）责任人和截止日期；3）标记有争议、未决事项。用表格输出，不需要开场白。”

提示

不知道从哪开始时，先问一句：“我想做 XX，你需要我提供哪些信息？”，让它先帮你梳理输入项。

技巧二：小步快跑，一次搞定一件事

把“读 50 页报告 → 写汇报 PPT → 发邮件”这类大任务拆成多轮：

  1. 读取报告 PDF，提炼 5 个核心结论，每条一句话并附原文页码。
  2. 基于这 5 条结论，写一份 15 页汇报大纲，聚焦与我业务相关的机会。
  3. 把第二页“机会分析”扩展成完整 PPT 页面内容，并发给领导。

技巧三：不满意就调整

官方列出四类调整方法：直接指出问题（“太长”“语气太正式”）、换角度重述需求、补充限制条件（受众/场景/格式/篇幅）、切换角色视角（老板/客户/产品经理/分析师）。

要点

官方比喻：把和 WorkBuddy 的对话，想象成在指导一个很勤奋、但需要反馈的实习生。 多轮打磨是常态，不是失败。

技巧四：给身份、给例子

  • 给身份：选择内置专家角色（法律顾问、产品经理、数据分析师、营销文案等），WorkBuddy 会优先沿该角色思路组织回答。
  • 给例子：「一个好的参考样本，胜过写十行抽象要求」——直接给一个满意样本并说“照这个来”。
你是一位在投行工作 10 年的财务分析师，以你见过最优秀的
研究报告为标准，帮我分析这家公司的财报。重点关注：
1）收入结构是否健康；2）现金流是否存在隐患；3）相比同行
的竞争优势。请给出明确投资建议；数据不足可大胆假设，但要
标注假设条件。我要的是有洞察力的分析，而不是数据搬运。

技巧五：用提示词模板

创建任务页按场景（日常办公、代码开发、设计创意）提供提示词模板。悬停模板会在输入框显示灰色预览文案（不进入草稿、不会被发送），点击才真正填入。切换场景时，「办公/开发」展示文字类任务，「设计」展示图片案例。

2.3 模式选择

官方提供三种工作模式，可通过输入框左侧 + 菜单切换（Plan 与 Ask 互斥，关闭后回到默认模式）：

模式 说明 适用场景
默认（Agent） 高效执行任务指令，可修改文件 文档生成、表格处理、文件整理
计划（Plan） 先规划任务，等你确认后再执行 多步骤任务、需审阅改动范围
仅问答（Ask） 适合问问题、找思路，不做执行 了解内容、确认需求
注意

官方文档中工作模式只有以上三种，不存在名为 “Act” 的模式；与之最接近的是默认（Agent）模式。

计划（Plan）模式

核心是「先出方案，再动手执行」——模型先补齐信息、给出可审阅的完整方案，确认后才执行，可以在几十秒内纠正方向，而不是等结果跑完才发现思路错了。

建议开启 Plan 默认模式更快
任务要拆成多个步骤 单点问答：查数字、问概念、翻译
需求模糊、有多种解法 明确的小改动
关键前提尚未确定 一句话即可执行
产出成本高，不想白跑 连续轻量追问

一句话判断：如果「怎么做」比「做出来」更值得先讨论，就开 Plan 模式；只要一个答案，就用默认模式。流程：打开 Plan 开关 → 回答关键变量提问（可跳过，模型自行假设并标注）→ 右侧查看完整方案 →「开始执行」或「调整计划」（确认前不会执行）。

说明

注意区分维度：工作模式（Agent/Plan/Ask）决定“怎么执行”，权限模式（默认权限/完全访问）决定“能访问什么”。两者是不同维度的设置。

2.4 模型选择与切换

按任务类型选模型系列

模型系列 适用场景
MiniMax Excel 处理、数据分析、PPT 生成，执行速度快
智谱 GLM 多步骤、长流程的复杂任务
Kimi 截图分析、图片转文档等视觉类任务
DeepSeek 日常问答、文案撰写，响应快、成本低
腾讯混元 中文写作、会议纪要、中文文档处理

三档模型模式

模式 适用场景 特点
快速模式 日常问答、格式转换、小段代码修改、文案润色 响应最快、消耗最低
均衡模式 写文档、分析数据、多文件代码改动 效果和速度兼顾，不确定时用它
极致模式 跨模块重构、多步骤推理、需反复验证的分析 稍慢、消耗高，复杂任务更稳

内置模型清单（部分）

模型 简介 功能
Hy4 preview / Hy3 混元新一代 / 混元思考模型 图片输入、思考模式
GLM-5.3 / 5.2 支持 1M 上下文窗口，擅长长程任务 图片输入、思考模式
GLM-5.3-Flash / 5.1 快速版 / 能力均衡适合日常 思考 / 推理模型
MiniMax-M3 / m2.7 原生多模态，擅长代码/智能体 / 性价比高 图片输入、推理模型
Kimi-K3 / K2.7-Code / K2.6 长程自主任务与前端开发 / 编程优化 / 日常 图片输入、推理模型
Deepseek-V4-Flash / Pro 旗舰模型，1M 上下文，速度优先 思考模式

相关配置项

  • 思考强度：越高做越多分析和自我检查，适合逻辑链长、易出错任务；默认档位已适配绝大多数场景，一般无需调整。
  • 上下文窗口：点输入框的「上下文用量圆环」，在「默认 / 适中 / 超长」间切换，仅对当前任务、下一轮生效。官方提醒：窗口并非越大越好。
  • 繁忙程度：悬停模型看信息卡，分空闲（绿）、轻微拥堵（橙）、极度拥堵（红，建议换模型）、不可用。
  • 经济模式：设置 → 智能体 → 经济模式（个人版默认开启），开启时自动压缩上下文降低积分消耗。
  • 自定义模型：支持提供商接入、本地部署（Ollama 默认端口 11434）、自定义 URL；参数仅保存在本地 workbuddy/models.json，费用向第三方支付。
注意

切换时机：对话中途切换会在下一轮生效，可能降低性能、增加积分消耗。模型下线时优先切到同系列新模型，无对应新模型则用系统默认；切换后思考强度与上下文窗口按新模型默认值。
