Task 6｜资料库与记忆（Memory）

材料留住，习惯记住

6.1 资料库是什么

官方定位：资料库是人和 Agent 共同的产物存放地，让 AI 生成的文件从“用完即散落”推进到“沉淀、管理、流转协同”的完整链路。它不是把文件堆在一起，而是让 MD、CSV、HTML 三种载体互相引用、彼此联动——文档被页面引用、表格被页面渲染，改一处、处处生效。

左侧边栏点击「资料库」进入。三块核心能力：01 内容管理 · 02 多人多 Agent 协作 · 03 轻量发布。

核心特性

  • 人与 Agent 同权限：Agent 读写资料库时权限与当前用户完全一致，不越权。
  • 一棵目录树：AI 三件套（MD/CSV/HTML）、办公文件（PDF/Word/PPT/Excel）、图片音视频统一归拢。
  • 个人与团队分区：「我的文档」放个人产出，「团队空间」放项目共享资料。
  • 改动闭环：从资料库添加到任务 → 基于资料提问 → 成果保存回资料库。
  • AI 修改可审阅可回退：对 MD 的修改不覆盖原文，以“待确认”呈现，接受后才写入。

容量配额（侧边栏底部显示容量条）：体验版 5GB、标准版 10GB、高级版 20GB、旗舰版 50GB；加入 Buddy One 后升级为 1TB 共享容量。办公与本地文件由腾讯网盘存储，WorkBuddy 中创建的内容存于 WorkBuddy 云端。

6.2 资料库使用与协作

存入资料的两种路径

  • 会话中保存：在生成产物的会话中要求 Agent 存入资料库，它会上传并告知位置。
  • 分享即存入：在产物点「分享 → 发布 → 发布为网站」，生成在线链接的同时，内容也会进入资料库。

MD / CSV / HTML 的分工

载体 角色 说明
MD 决定内容 文字与结构
CSV 存储数据 唯一数据源，由在线表格承载，多人同时维护
HTML 负责表达 通过表格 ID 读取数据实时渲染，CSV 更新页面随之刷新

任务中读取：文件详情页右上「⋯ → 添加到任务」，所选内容进入任务上下文后即可直接提问。编辑器：MD 支持划词菜单（AI 编辑/加粗/链接等）、目录导航、查找替换（Ctrl/⌘+F、Ctrl/⌘+H）、智能复制；HTML 支持手动编辑与选中元素唤起 AI 编辑。

协作共享

左栏「团队空间」点 + 新建空间，可用四种方式放资料：新建文档/表格、上传本地文件、剪藏网页链接、让 Agent 直接生成。空间菜单「邀请和管理成员」可复制链接邀请。成员权限四档：

权限 可做的事
查看 浏览内容，不能修改
编辑 新建、修改和整理内容
管理 管理成员与权限设置
无权限 不可访问
要点

Agent 按同一权限读取：“人看不到的内容，Agent 也读不到”，不必为 Agent 单独维护权限。审阅模式：AI 修改 MD 时标为“待确认”，列出“原文 / 改后”对照，只有点「接受」才写入正文；HTML 的 AI 修改则即时生效。

轻发布与知识库接入

发布为网站：页面右上「分享 → 发布 → 发布为网站」，开关默认关闭，开启后任何人凭链接可访问（域名 workbuddy.link），可随时关闭，发布前请确认内容适合公开。HTML + CSV 轻应用：把资料“变好看”（汇报、作品集）用一个 HTML，把资料“变能用”（工作台、看板、记账）用 HTML + CSV，实现数据在线存储与双向同步。

腾讯文档接入：侧边栏资料库 → 腾讯文档 → 立即前往授权（微信/QQ 扫码），获得登录用户的文档权限；支持导入本地文件/文件夹、语义搜索与关键词搜索、任务引用指定文件、把产物存回腾讯文档（MD 产物默认创建为智能文档）。企业账号仅支持端内部分操作，解绑仅个人账号可用。

6.3 记忆机制与身份文件

Memory 如何工作

官方导语：记忆让 WorkBuddy 记住你的偏好和习惯，对话越多，它就越懂你。它从会话历史中提取有价值的个人信息（事实信息、偏好习惯、人物关系、近期跟进事项等）形成「记忆数据」并定期更新；后续对话或任务执行时，把与当前请求相关的记忆作为背景信息一并参考。

  • 提取频率：每晚整理当天会话，仅你本人可见。
  • 入口：头像 →「设置 → 记忆」，可查看、编辑、删除或一键关闭。
  • 编辑方式：唤起对话框，用对话告诉它要记住或忘记什么。
  • 导入：可把其他 AI 上的使用习惯复制提示词、粘贴结果，点「添加到记忆」导入。
  • 用途：① 注入系统提示词作为上下文；② 支持对会话历史的检索（如“上周做过什么”）。
  • 成本与隐私：不消耗积分（WorkBuddy 自费）、不涉及第三方共享。
注意

记忆由模型自动抽取，可能有概括偏差或时效性问题，依赖它做重要判断前建议先核验。不希望被记住的信息可在「设置 → 记忆」删除或关闭；关闭或删除后相应数据停止用于后续对话，但已生成的输出不会追溯撤回。

身份文件

除云端记忆外，WorkBuddy 客户端还通过一组身份与记忆文件持久化“你是谁、用户是谁、项目惯例是什么”。这些文件是 Markdown 文本，可被编辑，构成跨会话的稳定上下文：

文件 作用
SOUL.md 定义助手的“灵魂”：核心价值、行为准则、风格与边界
IDENTITY.md 身份记录：名字、形象、气质等稳定身份信息
USER.md 用户画像：称呼、职业、偏好与关注点
MEMORY.md 长期记忆：跨项目或当前项目的精要笔记与约定
YYYY-MM-DD.md 工作日志：按天追加记录有长期价值的工作与决策
说明

身份文件属于客户端内置机制，公开帮助文档未逐项展开其完整规范；实际以你本地工作区中的文件为准。记忆分层（短期/长期）在公开文档中亦未定义，官方仅描述了“提取 → 形成记忆数据 → 每晚整理 → 注入上下文/检索历史”的处理流程。

6.4 资料库与记忆的分工

两者都服务于“为 Agent 提供上下文”，但定位不同。依据官方原文归纳如下（官方未设专门对比章节）：

维度 资料库（Library） 记忆（Memory）
存放对象 显式产物与文件：MD/CSV/HTML/PDF/Office/图片音视频 隐式个人信息：事实、偏好、人物关系、跟进事项
数据来源 人上传、Agent 生成、剪藏网页、知识库导入 模型自动从会话历史抽取
生成节奏 主动保存 / 任务产出保存 每晚自动整理更新
可见范围 个人、团队空间、发布链接（按权限） 仅本人可见
共享协作 多人多 Agent 协作、权限四档、轻发布 不共享、不用于多人协作
消费方式 添加到任务作为上下文，可读取/修改/回存 注入系统提示词、检索会话历史
积分 存储/检索不耗，加工分析按 AI 操作计 不涉及积分消耗
入口 左侧边栏「资料库」 头像 →「设置 → 记忆」
提示

一句话区分：资料库是对外的、可共享可协作的产物底座（显式、可审阅、可回存）；记忆是对内的、私人的个性化背景（自动抽取、隐式、仅本人可见）。前者强调团队流转与发布，后者强调习惯沉淀与隐私可控。
